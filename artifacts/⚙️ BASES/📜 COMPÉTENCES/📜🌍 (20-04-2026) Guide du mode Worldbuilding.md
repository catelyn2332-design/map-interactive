**Chap 1 •** 🗞️ **_Présentation générale_**
═════════════════════════
**✎** **_Description:_** _Le mode Worldbuilding sert à moi et l'IA à développer mon histoire sur des éléments ciblés avec des idées constructives et créatives, idéalement en activant DeepSearch._

**1•** ⏯️ **_Activation/désactivation_**
Le mode worldbuilding peut être aussi activé si je dis "aide-moi à développer".
-> ✅ Activation "Mode Worldbuilding ON 🌍"
-> ❌ Désactivation "Mode Worldbuilding OFF 🌍"
- 
**2•** ⌨️ **_Touches_**
- _🎨 Touche création:_ 
Agent A: Lire le "📜🧾 Guide de la rédaction de templates.txt" dans le répertoire local
Agent B: Raisonner sur les points nécessaires pour la template
Étape C: Permet de développer des fiches dans leur entièreté (que ce soit des templates, des catalogues, ou autres...)
- ❓ _Touche questionnaire:_
- _Touche statistique:_
Agent A: Chercher sur Internet (en utilisant l'analyse constructive qui permettra à trouver des idées concrètes sur un sujet afin d'améliorer le sujet en se basant sur les critères de référence)
Agent B: Discuter de comment améliorer les sujets en fonction des plusieurs critères de référence
- 📝 _Touche feedback:_
Agent A: Lire le(s) fichier(s) sur le sujet dans le répertoire local + le "📜✒️ Guide des projets en storytelling.txt"
Agent B: Discuter de comment améliorer les sujets en fonction des plusieurs critères de référence

5• 🌍 MODE WORLDBUILDING
═════════════════════════ 

1. TOUCHES
Une fois le mode activé, présenter quelles touches choisir. Touches (avec leurs emojis respectifs):
-> 🎨 Création (C): Créer un nouvel élément de worldbuilding
-> 📈 Amélioration (A): Commencer par un questionnaire, puis améliorer un sujet existant à partir des critères de référence, simples suggestions et/ou par recherche web
-> ❓Questionnaire (Q): Plusieurs questions ciblées qui aideront à affiner la vision du worldbuilding
-> 📊 Statistique (S): Aller sur le web et sur le répertoire local, noter le sujet à partir des critères de référence puis expliquer les résultats
-> 📃 Thèse (T): Expliquer ce que qui est compris dans le sujet pour voir si c'est exact
Lorsque la touche est indiquée, proposer les plusieurs sujets si je n'ai pas déjà fait mon choix:
🎲 Aléatoire (A)
✨ Nouveau (+)
🌌 Univers (U)
🗾 Nation (N)
🏘️ Ville (V)
⛳ Lieu (L)
⏳ Moment/timeline (M)
🌿 Espèce (E)
📪 Organisation (O)
👥 Groupe (G)
👤 Personnage (P)
